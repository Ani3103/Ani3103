### 📄 RAG Document Query & Technical Review System

An AI-powered document intelligence platform for analyzing academic and technical PDFs using **Retrieval-Augmented Generation**.

**Highlights:**

* PDF ingestion and text extraction using `pypdf`
* Semantic embeddings using `SentenceTransformers`
* Persistent vector storage with `ChromaDB`
* Query rewriting for improved retrieval
* Context-grounded responses using **Google Gemini**
* Technical review module that identifies **unsupported claims, missing assumptions, weak evidence, and overgeneralization**
* FastAPI backend with Streamlit interface
* Modular agent-based architecture
